# CyberAwareSA - Part 1
**Student Number:** ST10477640

## Project Overview
CyberAwareSA is a C# console application developed to provide cybersecurity awareness for South African citizens. The application focuses on identifying phishing attempts and promoting safe online habits.

## Folder Structure
* **Core:** Contains the main logic and engine of the bot.
* **UI:** Handles all user interface elements and console formatting.
* **Assets:** Stores media files, including the `.wav` audio greetings.
* **.github/workflows:** Contains the CI/CD pipeline for automated builds.

## Features implemented
* **Modular Design:** Separation of concerns between logic and interface.
* **Automated Build (CI):** Integrated GitHub Actions to verify code stability on every push.
* **Git Version Control:** Comprehensive commit history showing development stages.

## How to Run
1. Clone the repository.
2. Open the `.sln` file in Visual Studio.
3. Press `F5` to build and run the console application.
